HOW TO RUN
1. Install Python 3 if it is not already installed.
2. Open a terminal or command prompt in this folder.
3. Run: python student_marks_analyzer.py
   On some Windows installations, use: py student_marks_analyzer.py
4. Enter the student name and marks for five subjects. Each mark must be
   a number from 0 to 100.

WHAT IT DOES
- Validates input marks
- Calculates total and average
- Assigns a grade using explicit thresholds
- Displays a rule-based study suggestion

AI NOTE
This is a beginner rule-based decision program, not a trained machine-learning
model. Its output follows the rules explicitly written in the code.
